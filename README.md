# 📚 SmartStudy – Study Planner App

SmartStudy is an Android-based application designed to help students plan, organize, and manage their study schedules effectively.  
The app focuses on simplicity, productivity, and better time management.

## 🧰 Tech Stack

- **Language:** Kotlin  
- **Platform:** Android  
- **IDE:** Android Studio  
- **Build Tool:** Gradle  

## ✨ Features Overview

- 📝 Create and manage study tasks  
- 📆 Daily and weekly study planning  
- ⏱️ Time allocation for subjects  
- 📚 Subject-based organization  
- 📱 Simple and user-friendly interface  

## ▶️ How to Run the Project

1. Clone the repository  
2. Open in Android Studio  
3. Sync Gradle files  
4. Run on emulator or physical device
